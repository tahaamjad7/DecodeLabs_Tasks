# Task 1: Password Strength Checker

A simple Python script that evaluates password strength based on:
- Length
- Presence of lowercase letters
- Presence of uppercase letters
- Presence of numbers
- Presence of special symbols

## How it works
The script scores a password on "variety" (how many character types it uses)
combined with its length, then classifies it as **Weak**, **Medium**, or
**Strong**, along with a tip on how to improve it.

## How to run
```bash
python3 password_checker.py
```
You'll be prompted to type a password, and the script will print a full report.

## Key Skills
Python fundamentals, string handling, basic security awareness.
